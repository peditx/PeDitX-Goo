# PeDitX-Goo — guide for AI coding agents

PeDitX-Goo is the animated companion of **PeDitX-AI**, living at the top of the
screen. It is a shell, not an assistant: PeDitX-AI owns the persona, the memory,
the Skills, the access mode, the model endpoint and the key. Goo asks
`POST /api/chat` on PeDitX-AI's own local service (`http://127.0.0.1:8765` by
default), runs whatever tools the answer asks for through `POST /api/execute`,
and shows the reply. It holds no secret and has no model of its own — that is
the design, not an omission.

Two Tauri 2 apps, one code base:

- `linux/` — Rust + TypeScript, `.deb` / `.rpm`, character at the top of the screen.
- `windows/` — the same app with the platform layer swapped (Credential Manager,
  `RegisterHotKey`, WebView2, OLE drag), packaged as NSIS.

## Where things are

- `linux/src/`, `windows/src/` — the TypeScript front end (near-copies, kept in sync by hand).
  - `character/` — the character itself: `engine.ts` draws it on a Canvas,
    `greeting.ts` the launch animation, `minibots.ts` the pill versions.
  - `island/` — the window shell and its open/close state machine.
  - `views/` — the cards the island shows; `chat.ts` is the island chat.
  - `core/` — state, geometry, sounds, and `bridge.ts`, the one IPC layer.
  - `settings/main.ts` — the Settings window.
  - `goo/` — the full-screen chat window.
- `linux/src-tauri/src/`, `windows/src-tauri/src/` — the Rust side.
  - `backend.rs` — the whole PeDitX-AI client: the per-launch token, `/api/chat`,
    the tool loop, `/api/execute`, `/api/config`. **This is the file to change
    for wire behaviour.** It mirrors `web/index.html`'s `send()` in the
    PeDitX-AI repo; change them together.
  - `chat.rs` — the transcript, in the shape `/api/chat` expects. Nothing else.
  - `settings.rs` — preferences (JSON). No secrets: there are none to hold.
  - `island.rs` — window geometry and click-through; `tray.rs` — the tray menu.
- `sounds/` — the 28 WAVs, generated by `node scripts/gen-sounds.mjs`.
- `linux/scripts/gen-icons.mjs` — draws every app icon in code; `npm run icons`.
- `LICENSE` (MIT) and `LICENSE-ASSETS.md` (what is **not** MIT) — read both.

## Build

Nothing is compiled on a development machine. Edit, run read-only checks, push,
and let the workflow do it: `linux.yml` (deb/rpm + Rust tests on every push) and
`windows.yml` (NSIS, on tag or dispatch).

Static checks before a push:

```bash
rustfmt --edition 2021 --check src-tauri/src/*.rs   # the upstream tree had 142 diffs at this rustfmt; expect the same class
npx tsc --noEmit                                     # must be 0
python3 -c "import json;json.load(open('src-tauri/tauri.conf.json'))"
node scripts/gen-icons.mjs && node --check scripts/pack.mjs
```

## Rules

- Swift 6 does not apply here — this is Rust + TypeScript. No third-party
  dependency for anything a few lines can do; `gen-icons.mjs` and
  `gen-sounds.mjs` ship zero dependencies on purpose.
- The character is drawn in code (Canvas), no Rive/Lottie/images.
- **Goo holds no secret and never will.** The API key is PeDitX-AI's and stays
  in its config. The only credential Goo ever handles is PeDitX-AI's per-launch
  token, read from the page it serves and never stored. The address of
  PeDitX-AI is not a secret and lives in `settings.json`.
- No telemetry. The only network call is to the PeDitX-AI address the user
  configured. Nothing is upgraded from `http://` to `https://`, ever.
- Never block: if the app does not answer, the caller gives up rather than hangs.
  A failed turn is dropped whole so the question can be asked again.
- Performance: 0 % CPU when the island is hidden (the cursor poll parks itself).
- Identifier `fr.peditx.goo`, product name `PeDitX-Goo`, Tauri identifier shared
  by both platforms. Preferences depend on these — do not change them without a
  migration.
- Visual changes follow PeDitXOS: the palette in `src/style.css`
  (`--focus #2F6BFF`, `--ink`, `--panel`, `--line`) and the spring
  `cubic-bezier(.32,1.22,.42,1)`.
